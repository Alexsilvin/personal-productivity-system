## Product principles

1. Protect attention before optimizing utilization.
2. Make plans explicit, flexible, and explainable.
3. Keep the user in control of automation.
4. Prefer small, reversible changes over disruptive replanning.
5. Treat privacy and offline operation as core requirements.
