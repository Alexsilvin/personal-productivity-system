# Roadmap

## Phase 1: Foundation

- Define the domain model and local persistence.
- Build task capture, task editing, and day planning.
- Implement deterministic scheduling with locked blocks.
- Add basic explanations and focused tests.

## Phase 2: Adaptation

- Add interruption capture and incremental replanning.
- Add recurring tasks, dependencies, and deadline-risk states.
- Add configurable local notifications.
- Add daily review and plan history.

## Phase 3: Multi-device

- Add encrypted account sync and conflict handling.
- Ship mobile and desktop platform adapters.
- Add calendar integration and background refresh.
- Expand accessibility and offline test coverage.

## Phase 4: Refinement

- Improve scheduling preferences using explicit user feedback.
- Add analytics that are privacy-preserving and opt-in.
- Evaluate assisted estimates and recommendations without making them mandatory.

## Out of scope initially

Team scheduling, social features, opaque productivity scores, and autonomous changes to high-impact deadlines.
